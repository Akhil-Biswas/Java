# Classes and Objects

## Overview

Classes and objects are fundamental concepts in Object-Oriented Programming. A class is a blueprint or template for creating objects, while an object is an instance of a class.

## Topics

1. **Defining a Class**
   - Class syntax
   - Class members (fields and methods)
   - Naming conventions

2. **Creating Objects**
   - Using the `new` keyword
   - Object reference
   - Memory allocation

3. **Constructors**
   - Default constructor
   - Parameterized constructor
   - Constructor overloading
   - Copy constructor

4. **The `this` Keyword**
   - Referring to instance variables
   - Calling other constructors
   - Passing current object as parameter

5. **Instance vs Static Members**
   - Instance variables and methods
   - Static variables and methods
   - When to use static

6. **Methods**
   - Method declaration
   - Parameters and return types
   - Method overloading
   - Variable arguments (varargs)

## Example Structure

```java
public class ClassName {
    // Fields (instance variables)
    private int field1;
    
    // Constructor
    public ClassName(int field1) {
        this.field1 = field1;
    }
    
    // Methods
    public void methodName() {
        // method body
    }
}
```
