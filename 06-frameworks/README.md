# Java Frameworks

This section covers popular Java frameworks and libraries used in enterprise development.

## Topics Covered

### 01-spring
- Spring Framework introduction
- Dependency Injection (DI)
- Inversion of Control (IoC)
- Spring Boot basics
- Spring MVC
- REST APIs with Spring
- Spring Data JPA
- Spring Security basics

### 02-hibernate
- ORM (Object-Relational Mapping) concepts
- Hibernate configuration
- Entity mapping
- Annotations vs XML configuration
- Session and SessionFactory
- CRUD operations
- HQL (Hibernate Query Language)
- Criteria API
- Caching in Hibernate
- Relationships (One-to-One, One-to-Many, Many-to-Many)

### 03-junit
- Unit testing fundamentals
- JUnit 5 basics
- Annotations: @Test, @BeforeEach, @AfterEach, etc.
- Assertions
- Parameterized tests
- Test lifecycle
- Mocking with Mockito
- Test-Driven Development (TDD)
- Best practices for unit testing

## Learning Path

These frameworks are widely used in professional Java development. Start with the basics of each framework and build practical examples.

## Prerequisites

Before diving into frameworks:
- Strong understanding of Java basics and OOP
- Familiarity with design patterns
- Basic understanding of databases (for Hibernate)
- Understanding of web concepts (for Spring MVC)
