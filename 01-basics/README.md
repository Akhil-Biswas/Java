# Java Basics

This section covers fundamental Java concepts essential for beginners.

## Topics Covered

### 01-introduction
- Setting up Java development environment
- Understanding JDK, JVM, and JRE
- First Java program (Hello World)
- Java compilation and execution process

### 02-syntax
- Java program structure
- Comments (single-line, multi-line, Javadoc)
- Naming conventions
- Keywords and identifiers
- Statements and blocks

### 03-data-types
- Primitive types: byte, short, int, long, float, double, char, boolean
- Reference types
- Type casting and conversion
- Wrapper classes
- Variables and constants

### 04-operators
- Arithmetic operators (+, -, *, /, %)
- Assignment operators
- Comparison operators
- Logical operators (&&, ||, !)
- Bitwise operators
- Ternary operator
- Operator precedence

### 05-control-flow
- if-else statements
- switch-case statements
- for loops
- while loops
- do-while loops
- break and continue statements
- Enhanced for loop

## Learning Path

Start with 01-introduction and progress sequentially through each topic. Practice writing code examples for each concept before moving to the next topic.
