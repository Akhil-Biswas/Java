# Java Notes Repository

A comprehensive collection of Java programming notes, examples, and projects organized by topics.

## 📚 Directory Structure

### 01-basics
Fundamental Java concepts for beginners
- **01-introduction**: Java setup, JDK, JVM, JRE basics
- **02-syntax**: Java syntax rules, naming conventions
- **03-data-types**: Primitive and reference data types
- **04-operators**: Arithmetic, logical, bitwise operators
- **05-control-flow**: if-else, switch, loops

### 02-oop
Object-Oriented Programming concepts
- **01-classes-and-objects**: Class structure, object creation
- **02-inheritance**: Extending classes, super keyword
- **03-polymorphism**: Method overloading and overriding
- **04-abstraction**: Abstract classes and methods
- **05-encapsulation**: Access modifiers, getters/setters
- **06-interfaces**: Interface implementation, default methods

### 03-advanced
Advanced Java topics
- **01-exception-handling**: Try-catch, custom exceptions
- **02-collections**: List, Set, Map interfaces and implementations
- **03-generics**: Generic classes, methods, wildcards
- **04-multithreading**: Threads, synchronization, concurrency
- **05-streams-and-lambda**: Functional programming, Stream API
- **06-file-io**: File handling, serialization

### 04-data-structures
Common data structures implementations
- **01-arrays**: Array operations and algorithms
- **02-linked-lists**: Singly/doubly linked lists
- **03-stacks-and-queues**: Stack and Queue implementations
- **04-trees**: Binary trees, BST, AVL trees
- **05-graphs**: Graph representations and algorithms
- **06-hash-tables**: HashMap implementations

### 05-algorithms
Algorithm implementations and analysis
- **01-sorting**: Bubble, merge, quick sort, etc.
- **02-searching**: Linear, binary search
- **03-recursion**: Recursive problem solving
- **04-dynamic-programming**: DP patterns and problems

### 06-frameworks
Popular Java frameworks
- **01-spring**: Spring Framework basics
- **02-hibernate**: ORM with Hibernate
- **03-junit**: Unit testing with JUnit

### 07-projects
Practical projects organized by difficulty
- **01-beginner**: Simple console applications
- **02-intermediate**: GUI applications, small systems
- **03-advanced**: Complex applications, full-stack projects

## 🚀 How to Use

1. Navigate to the topic you want to learn
2. Each directory contains notes, code examples, and exercises
3. Follow the numbered order for a structured learning path
4. Practice with the projects in the 07-projects directory

Feel free to add your own notes and examples following the existing structure!
