# Data Structures

This section covers implementation and usage of common data structures in Java.

## Topics Covered

### 01-arrays
- Array declaration and initialization
- Multi-dimensional arrays
- Array manipulation
- Common array algorithms
- Arrays class utilities

### 02-linked-lists
- Singly linked list implementation
- Doubly linked list implementation
- Circular linked list
- Operations: insertion, deletion, traversal
- Use cases and complexity analysis

### 03-stacks-and-queues
- Stack implementation (array-based, linked list-based)
- Stack operations: push, pop, peek
- Queue implementation
- Queue operations: enqueue, dequeue
- Priority queue
- Deque (double-ended queue)

### 04-trees
- Binary tree basics
- Binary search tree (BST)
- Tree traversals (inorder, preorder, postorder, level-order)
- AVL trees
- Tree operations: insertion, deletion, search
- Common tree problems

### 05-graphs
- Graph representation (adjacency matrix, adjacency list)
- Graph traversals (BFS, DFS)
- Shortest path algorithms (Dijkstra, Bellman-Ford)
- Minimum spanning tree (Prim, Kruskal)
- Topological sorting

### 06-hash-tables
- Hash function concepts
- Collision resolution (chaining, open addressing)
- HashMap implementation
- Load factor and rehashing
- Applications of hashing

## Learning Path

Understanding data structures is fundamental for efficient algorithm design and problem-solving.
